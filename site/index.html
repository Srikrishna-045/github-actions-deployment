Automated Website Deployment Using GitHub Actions

Push your code to GitHub and your website goes live on its own. No manual uploads, no copying files, no waiting.

Get Started

About the Project

This project shows how a simple website can be published automatically every time the code changes.

What is DevOps?

DevOps is a way of working where developers and operations teams cooperate and use automation to build, test and release software quickly and reliably.

What is CI/CD?

Continuous Integration (CI) checks every code change. Continuous Deployment (CD) publishes the change automatically. Together they form a pipeline from code to live website.

Why automate deployment?

Manual deployment is slow and easy to get wrong. Automation repeats the same steps the same way every time, so releases are faster and safer.

Technologies Used

Only simple, free tools are used in this project.

HTML5

Builds the structure and content of the web page.

CSS3

Controls colours, layout, spacing and the responsive design.

Git

Tracks every change made to the project files on your computer.

GitHub

Stores the project online and lets Git changes be shared.

GitHub Actions

Runs the automatic workflow that deploys the website.

GitHub Pages

Hosts the website and gives it a public web address.

How It Works

Six steps take a code change from your computer to the live website.

  1. 1

    Developer writes code

    The website files are edited in Visual Studio Code.

  2. 2

    Code is committed using Git

    Git saves the changes as a commit with a short message.

  3. 3

    Code is pushed to GitHub

    The commit is uploaded to the main branch of the repository.

  4. 4

    GitHub Actions triggers automatically

    The push event starts the workflow without any manual action.

  5. 5

    Deployment workflow executes

    The workflow checks out the code, packages the site folder and deploys it.

  6. 6

    Website is published

    GitHub Pages serves the new version at a public URL.
